# Pradhan Homestay

A responsive multi-page hotel website for Pradhan Homestay in Badamtam, Naya Busty, Lebong, Darjeeling, West Bengal 734105.

## Run locally

This is a deployment-ready static site. Open `index.html` directly in a browser, or run a local server for the best experience:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Included

- Responsive HTML5 pages for the home, rooms, dining, events, gallery, attractions, contact, about, offers, terms and privacy sections.
- Shared CSS design system with the paper-cut mountain visual language.
- Vanilla JavaScript for mobile navigation, hero slider, gallery lightbox and demo form validation feedback.
- Unsplash image placeholders using locations outside Darjeeling for the visual assets.
- Booking engine and Google Maps areas are structured as integration-ready placeholders. Replace the form handler and map iframe URL with production services before launch.
- SEO-ready titles, descriptions, semantic sections and lazy-loaded gallery images.

## Deployment

Upload the folder contents to any static host such as Netlify, Vercel, GitHub Pages or an Apache/Nginx web root. Set `index.html` as the entry document and replace placeholder contact details or image URLs as needed.
